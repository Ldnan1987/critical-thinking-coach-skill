# 批判性思维教练 · critical-thinking-coach

一个 Kimi / Claude Code 兼容的 AI 技能包（Skill）：把美国大学批判性思维经典教材《逻辑是练出来的》（*A Workbook for Arguments*）的 50 条论证规则，提炼成 **9 张可执行技能卡**。

> 拆论证、识破统计陷阱、检验因果、判断专家可信度、写说服性文章、建设性辩论、查 22 种逻辑谬误——装上后直接说人话就能调用，思考、写作、吵架都更有底气。

## 9 张技能卡

| # | 技能 | 干什么用 |
|---|---|---|
| 01 | 前提—结论拆解法 | 分析任何一段话/文章/观点有没有道理 |
| 02 | 数字三问 | 拆穿统计陷阱、标题党（分母？基线？样本量？） |
| 03 | 因果四排查 | 检验"X 导致 Y"（巧合？反向因果？第三因？） |
| 04 | 主动找反例 | 重要决策前的最后自查，给判断划边界 |
| 05 | 信源三问 | 判断专家/大 V/网传说法可不可信 |
| 06 | 详论五步 | 写方案/论文/提案，把观点构建成完整论证 |
| 07 | 倾听—共识—正面观点 | 家庭争执/会议分歧/论战中的建设性辩论 |
| 08 | 议论文六步 | 写出有说服力的文章 |
| 09 | 谬误速查表 | 22 种常见论证谬误分 5 组速查，发现漏洞并修正 |

## 安装

把 `critical-thinking-coach/` 文件夹放入技能目录：

```
~/.config/agents/skills/        # 推荐（macOS/Linux/Windows 通用）
~/.kimi/skills/                 # 或 Kimi Code 用户目录
<你的项目>/.agents/skills/       # 或项目级目录
```

或 `git clone` 本仓库后复制 `critical-thinking-coach/` 到上述任一目录。

## 使用

装好后用自然语言提需求即可自动触发，例如：

- "帮我分析这段论证有没有道理：……"
- "这个新闻说喝咖啡的人更长寿，靠谱吗？"
- "帮我构建一个说服老板加预算的论证"
- "检查我这篇文章有没有逻辑漏洞"
